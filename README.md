# مستر فهيم — وحش الفيزياء للثانوية العامة

تطبيق تعليمي تفاعلي باللغة العربية لطلاب الثانوية العامة المصرية، يضم شرح الفصول، مدرسًا ذكيًا، حلًا للمسائل، اختبارات، معامل تفاعلية وورقة قوانين.

## المتطلبات

- Node.js 22.x
- npm 10.9.9
- مفتاح Google Gemini API لتفعيل المحادثة وحل المسائل وإنشاء الاختبارات والصوت.

## التشغيل محليًا

```bash
npm ci
cp .env.example .env
```

افتح `.env` وأضف مفتاحك في `GEMINI_API_KEY`. لا تضع المفتاح في ملفات الواجهة أو تشاركه علنًا.

```bash
npm run dev
```

يفتح التطبيق عادةً على `http://localhost:3000`.

## فحص وبناء نسخة الإنتاج

```bash
npm run lint
npm run build
npm start
```

يُبنى الموقع داخل `dist/` ويُجهّز الخادم في `server.js`. يستمع الخادم إلى قيمة `PORT` التي توفرها منصة الاستضافة، أو إلى المنفذ 3000 محليًا. مسار فحص الصحة هو `/healthz`.

## النشر باستخدام Docker

المشروع يتضمن `Dockerfile` جاهزًا. انشر المستودع على أي منصة تدعم Docker، ثم أضف متغير البيئة السري التالي من لوحة المنصة:

- `GEMINI_API_KEY` — مفتاح Google Gemini API.

اضبط فحص الصحة على `/healthz`. لا ترفع ملف `.env` إلى Git أو إلى الحزمة المنشورة. ويمكن كذلك تشغيل المشروع على منصات Node.js باستخدام `npm ci`, `npm run build`, ثم `npm start`، مع ضبط `GEMINI_API_KEY` و`PORT` في إعدادات الخدمة.

## ملاحظات قبل الإطلاق العام

- اختبر وظائف الذكاء الاصطناعي بمفتاح صالح؛ من دون المفتاح ستظل بعض الوظائف معطلة أو تعمل بردود احتياطية محدودة.
- راجع أسماء نماذج Gemini وإتاحتها في حسابك، لأن توافر النماذج والحصص يتغير بحسب الحساب والمنطقة.
- فعّل حدود استخدام وفوترة مناسبة لدى مزود الذكاء الاصطناعي، وراقب الاستهلاك عند فتح الموقع للجمهور.
- أضف رابط النطاق الحقيقي إلى وسوم المشاركة الاجتماعية بعد حجزه، واختبر الموقع على الهاتف قبل الإعلان عنه.

## الأمان

مفتاح Gemini يُقرأ من الخادم فقط. لا تضع أسرارًا في `VITE_*` أو في الشيفرة الأمامية. ملف `.env` مستثنى من Git.
